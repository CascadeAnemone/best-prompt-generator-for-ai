## ❓ What Is a Prompt Generator

| **Term** | **Description** |
|-----------|-----------------|
| **Prompt** | Instruction to an AI model |

| **Variable** | Placeholder you fill in |
| **Chain** | Multi-step reasoning flow |
| **Role** | Persona the model adopts |
| **Temperature** | Randomness setting |

**Why use a prompt generator?**
- ✅ Stop guessing wording
- ✅ Reuse proven structures
- ✅ Compare variants
- ✅ Export across tools
- ✅ Works with any model
